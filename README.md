# Quarkus Queryable

Queryable is a Quarkus extension that adds annotation-driven filtering to
collection endpoints generated by Hibernate ORM REST Data with Panache.

## Overview

REST Data provides CRUD operations, count endpoints, OpenAPI support and
transaction handling. Queryable adds a query language for filtering collection
results using entity annotations, Hibernate filters and custom Criteria API
predicates.

For example, annotate an entity to expose a collection endpoint and its
queryable fields:

```java
@Entity
@QRs("/api/developers")
@QOrderBy("surname asc")
public class Developer extends PanacheEntityBase {

    @Id
    @GeneratedValue
    @QList
    public Long id;

    @QLike
    @QRLike
    @QLLike
    public String surname;

    @Q
    public Integer experienceYears;

    @QList
    public String team_uuid;
}
```

The generated collection endpoint accepts filters such as:

```text
GET /api/developers?like.surname=pi
GET /api/developers?notlike.surname=pi
GET /api/developers?ie.surname
GET /api/developers?nie.surname
GET /api/developers?rlike.surname=pi
GET /api/developers?llike.surname=zza
GET /api/developers?gte.experienceYears=3&lt.experienceYears=10
GET /api/developers?obj.team_uuid=<uuid>
```

The other REST Data operations remain available, including:

```text
POST   /api/developers
GET    /api/developers/{id}
PUT    /api/developers/{id}
DELETE /api/developers/{id}
GET    /api/developers/count
```

## Installation

> These Quarkiverse coordinates are not published yet. The version below is the
> current development version; compatibility with Quarkus 4 is not yet verified.

### Quarkus CLI

```bash
quarkus ext add io.quarkiverse.queryable:quarkus-queryable
```

To create a new application with the extension:

```bash
quarkus create app my-app -x=io.quarkiverse.queryable:quarkus-queryable
```

### Maven

```xml
<dependency>
    <groupId>io.quarkiverse.queryable</groupId>
    <artifactId>quarkus-queryable</artifactId>
    <version>4.0.3</version>
</dependency>
```

Applications must also include a JDBC driver and a JSON extension, for example:

```xml
<dependency>
    <groupId>io.quarkus</groupId>
    <artifactId>quarkus-jdbc-postgresql</artifactId>
</dependency>
<dependency>
    <groupId>io.quarkus</groupId>
    <artifactId>quarkus-rest-jackson</artifactId>
</dependency>
```

### Gradle

```groovy
implementation 'io.quarkiverse.queryable:quarkus-queryable:4.0.3'
```

## Features

- Annotation-driven filters, sorting and logical deletion.
- Equality, inequality and inclusive or exclusive range filters with `@Q`.
- Case-insensitive substring, negated substring, starts-with and ends-with filters.
- Empty and non-empty string checks with `@QLike`.
- Hibernate filter integration with `@QFilter`.
- Custom filters through `QueryableFilter<T>` and the Criteria API.
- REST lifecycle callbacks through `QueryableRsListener<T>`.
- Standard Quarkus security configuration.

## Building from source

```bash
git clone https://github.com/quarkiverse/quarkus-queryable.git
cd quarkus-queryable
mvn clean install
```

The repository includes an integration application and a standalone consumer
test:

```bash
mvn install -DskipTests
mvn -f consumer-tests/pom.xml test
```
